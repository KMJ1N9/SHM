## 三、项目经历（格式 OK，内容要加成果）

### 当前问题
- 写了 7 条"做了什么"，但没写"做出什么效果"
- 缺少量化成果（数据提升、效率提升）
- 对后端岗位没突出高并发/微服务价值

### 正确写法：背景 → 技术 → 职责 → 成果

每一条应该包含：
> 用 [什么技能] → 解决 [什么问题] → 达到 [什么成果]

### 可量化的成果举例

| 你实际做的 | 可以这样量化 |
|-----------|------------|
| Redis 缓存商品列表 | "商品列表查询响应从 200ms 降至 5ms" |
| Docker Compose 一键部署 | "部署时间从逐个启动 5 分钟降至 30 秒" |
| 双后端 API 契约一致性 | "43 个 API 端点双后端零差异" |
| JWT 无感刷新 | "用户会话有效期从 30 分钟延长至 7 天无感知" |
| Python 自动化测试 | "14 个核心 API 回归测试从手动 20 分钟降至 3 秒" |

### 改动方向
1. 每条亮点加量化成果
2. 突出微服务/高并发设计（Gateway 路由、Sentinel 流控、Redis 缓存）
3. 后端岗位版：弱化前端描述，强化分布式能力
